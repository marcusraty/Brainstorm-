# Triage labels

The `triage` skill isn't installed, so only one label from Matt's vocabulary is used here:

| Role | Label | Applied by |
|---|---|---|
| ready-for-agent | `ready-for-agent` | `/to-spec` (the spec issue) and `/to-tickets` (each build ticket): agent-grabbable by construction |
